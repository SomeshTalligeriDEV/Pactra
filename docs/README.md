The PDF describes the inspected implementation, separates historical evidence from fresh verification, and records deployment limitations. It is not an audit certificate.

To rebuild, install `reportlab` in a Python environment and run `python3 scripts/build_architecture_pdf.py` from the project root. The generator uses Arial if available and otherwise falls back to Helvetica. All diagrams are vector artwork generated by the script.

The source uses `pactra.example` as a deployment placeholder. Configure a real origin before deployment. Existing chain addresses and numeric evidence are historical; renaming source does not update them on chain.
