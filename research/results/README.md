# Experimental evidence

These are local measurements for the Pactra preprint, version 1.0.0.
The implementation revision is identified in the paper and release README.
No measurement was obtained from the archival Arc deployment.

## Environment and reproduction

macOS Darwin 25.6.0 arm64; Foundry 1.8.3, commit
`cae51ad458f6abb64852b7709eb784352429825d`; Node.js v22.14.0 with
`NODE_OPTIONS=--experimental-strip-types`; Solidity 0.8.28, optimizer 200
runs, Shanghai EVM, no via-IR, no bytecode metadata hash. The contract test
library is pinned by `packages/contracts/foundry.lock` in the repository.
From the implementation checkout, with Foundry and npm dependencies installed:

```sh
(cd packages/contracts && forge test --fuzz-seed 0x5042002) > research/results/contract-tests-final.txt 2>&1
./benchmarks/run-gas-report.sh
./benchmarks/run-depth-sweep.sh
NODE_OPTIONS=--experimental-strip-types ./benchmarks/run-g7-eval.sh
cp packages/contracts/out/g4-search.json research/results/g4-search-final.json
python3 benchmarks/validate-results.py
```

Benchmark shell scripts require the implementation checkout. The Python
validator requires only this publication's results and Python 3 standard
library. Shell scripts name outputs using the current UTC date; the validator
checks the archived 2026-09-18 files. Compare later dated reruns with these.

## File interpretation

- `contract-tests-final.txt`: complete `forge test` output. 101 is Foundry's
  reported-case count: 100 `test*` functions and one grouped stateful invariant
  campaign containing three `invariant_*` functions. Seven fuzz functions each
  execute 512 runs; the stateful campaign executes 256 sequences of 32 handler
  calls. The campaign includes deliberately invalid inputs that can revert;
  these are not failed tests.
- `gas-report-2026-09-18.txt`: complete full-suite gas-report output, seed
  `0x5042002`. This includes the depth benchmark as well as fixed, fuzz,
  stateful, and generated-search tests. Min/average/median/max/call-count are
  function-call aggregates, not network transaction fees. Instrumented gas
  reporting can alter paths in gas-sensitive fuzz input selection, so its
  handler counts need not equal the noninstrumented run. The paper table is
  transcribed from this file, not from an earlier 100-case suite. Runtime
  durations and some stateful sequences can differ across machines/reruns.
- `g4-search-final.json`: generated by G4's test, 1,200 scripted strategies,
  45,360 attempted draws, 33,327 accepted, 12,033 refused, zero observed bound
  violations. This is empirical coverage, not formal verification.
- `depth-sweep-2026-09-18.csv`: `gasleft()` call intervals for the first draw
  on six separately constructed mandate paths at depths 1, 2, 4, 8, 16, 24.
  All execute inside one test transaction with shared vault/token/Gateway
  mocks. Setup warms registry storage; shared token state and memory can
  differ between points. Fresh spending counters require zero-to-nonzero
  writes. No independent cold-transaction comparison or uncertainty estimate
  is claimed. OLS: intercept 206,635 and slope 98,417 (rounded), R-squared
  0.999945. Branching scaling and real block-gas thresholds were not measured.
- `g7-eval-2026-09-18.txt`: local Anvil mock-settlement evaluation. Three
  conditions (Pactra, shared-cap, independent-wallets), two deterministic
  scenarios, three repetitions each. Spend and loop totals sum three runs;
  initial exposure is per run. Windows advance between runs; the chain and
  lifetime state are retained. The normal scenario gives each worker a $20
  allowance, so isolated upfront funding totals $40. The loop scenario gives
  each worker $10, totaling $20. Pactra and shared-cap use a $20 root budget
  in both scenarios. Baseline application counters reset per run; leftover
  mock-wallet funds can remain but cannot increase that run's allowance.

In the loop scenario, the $3.50 declared-address cap permits six $0.51
loop purchases ($3.06) and refuses a seventh ($3.57 would exceed the cap).
The left worker first buys useful $0.35 and $0.42 resources from other sellers.
Loop totals are $9.18 / $56.61 / $27.54 for Pactra / shared-cap / independent
wallets. Both Pactra and independent wallets complete all three briefs;
shared-cap completes zero. The 1:3 and approximately 1:6.17 loop ratios
compare these settings; the experiment does not isolate ancestor accounting
from concentration and does not evaluate adaptive or colluding agents.
Ordinary draws exclude owner `release()` overrides and withdrawals. Declared
counterparty windows may be out of phase with node windows. Settlement
recipients are not cryptographically bound to draw declarations.
